cvitae-agent-runtime

An API, not a site. It runs four capabilities — extract_cv, translate_cv, analyze_offer and verify_recipient — against whichever model provider the caller names, using the API key the caller sends.

It holds no credential of its own and stores nothing: no CV, no offers, no logs of what passed through. A request without a key is refused rather than answered on somebody else's.

/health says what it will run.
